はじめての方へ(使い方)
  1. 認定情報(認定調査票・主治医意見書・特記事項)の個人情報をすべてマスキングし、PDF化します。
  2. 「利用者名」欄にお名前を入れ、PDFを読み込みます(文字を貼り付けてもOK)。本人・家族の意向が聞き取れていれば入力します。
  3. 「AIで下書き作成」を押すと、24項目の評価と、見通し・ニーズ【案】・優先順位の下書きができます。数分かかることがあります。
  4. 下に出るチェック結果を確認し、必要なら「2」の欄の文字を直して「様式に反映」を押します。
  5. マス目をクリックするか「行コピー」でコピーし、お使いの介護ソフトの同じ欄に貼り付けて反映します。急ぎのときは「標準様式で印刷・PDF保存」でそのまま印刷もできます。
  6. 見通し・ニーズ【案】・優先順位は下書きです。「面談で確認すべき事項」を参考に面談を行い、ケアマネジャーが確定してください。
体験版のご利用にあたって

この体験版は、架空の事例(ペルソナ)でAIの下書き作成を試していただくためのものです。AIはクラウド(インターネット上のサーバー)で動くため、画面の内容はAIの処理のためにインターネットを通じて送られます。

  • 実在の方の情報は入力しないでください。認定情報はペルソナから選ぶ方式で、本人・家族の意向の欄だけ自由に書き換えられます。
  • AIの処理は、送られた内容を学習に使わない事業者に限定しています。
  • たくさんの方に試していただくため、1日に使える回数に上限があります。
  • 実際の業務でお使いになる場合は、パソコンの中だけで完結する「ローカルAI版」をご検討ください。
