はじめての方へ(使い方)
  1. 「利用者名」欄にお名前を入れます。課題整理総括表ツールで作った結果(「2」の欄の文字)を、アセスメント欄に貼り付けます。
  2. 面談で確認した本人・家族の意向を入力します(必須)。サービスの追加・変更があれば「サービスの追加・変更がある場合」で文例を選びます。
  3. 「AIで下書き作成」を押すと、第1表・第2表の下書きができます。数分かかることがあります。
  4. 黄色のハイライト((要確認)・(仮置き)・空欄)とチェック結果を確認し、必要なら「2」の欄の文字を直して「様式に反映」を押します。
  5. 欄ごとの「コピー」やマス目のクリックでコピーし、お使いの介護ソフトの同じ欄に貼り付けて反映します。急ぎのときは「標準様式で印刷・PDF保存」でそのまま印刷もできます。
  6. 担当者会議・事業所との調整・本人への説明と同意を経て、ケアプランとして確定してください。
体験版のご利用にあたって

この体験版は、架空の事例(ペルソナ)でAIの下書き作成を試していただくためのものです。AIはクラウド(インターネット上のサーバー)で動くため、画面の内容はAIの処理のためにインターネットを通じて送られます。

  • 実在の方の情報は入力しないでください。認定情報はペルソナから選ぶ方式で、本人・家族の意向の欄だけ自由に書き換えられます。
  • AIの処理は、送られた内容を学習に使わない事業者に限定しています。
  • たくさんの方に試していただくため、1日に使える回数に上限があります。
  • 実際の業務でお使いになる場合は、パソコンの中だけで完結する「ローカルAI版」をご検討ください。
