# ビッグファイブ性格傾向チェック

自己理解、人材育成、1on1、キャリア形成の対話を支援するための、HTML / CSS / JavaScript だけで動く静的Webアプリです。フレームワーク、外部API、外部CDN、ログイン、アクセス解析は使用していません。

## ファイル一覧

- `index.html` — 画面の構造とアクセシブルなフォーム
- `style.css` — レスポンシブ表示、フォーカス表示、印刷用スタイル
- `app.js` — 30問の設問データ、逆転採点、結果表示、端末内保存
- `README.md` — この説明書

## ローカルで確認する

`index.html` をブラウザで直接開くだけで利用できます。よりWebサーバーに近い形で確認する場合は、プロジェクトのフォルダで次を実行してください（Pythonがある場合）。

```sh
python -m http.server 8000
```

次に `http://localhost:8000/` を開きます。確認する項目は、全30問の回答、逆転項目（反転して採点される設問）、未回答時の案内、端末内保存・再表示・削除、印刷プレビュー、スマホ幅のレイアウトです。

## GitHub Pagesで公開する

1. この4ファイルをGitHubリポジトリの公開したいフォルダ（通常はリポジトリ直下）に追加して、GitHubへpushします。
2. GitHubリポジトリの **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. 公開するブランチ（例: `main`）とフォルダ（`/(root)`）を選び、**Save** を押します。
5. 数分後、表示されるURLを開いて確認します。

## プライバシー方針

- 回答、スコア、表示名は外部送信しません。通信処理、外部API、アクセス解析は実装していません。
- 「この端末に結果を保存」を選んだ時だけ、回答・表示名・実施日を利用者のブラウザの `localStorage` に保存します。この保存データは同じ端末・同じブラウザ内に限られます。
- 「保存した結果を削除」で、保存済みデータをそのブラウザから削除できます。
- 印刷／PDF保存はブラウザの標準印刷機能を使います。外部のPDF生成サービスには送信しません。
